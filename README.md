# Exercícios Simples de JavaScript

Exercícios feitos durante o curso de JavaScript do Curso em Vídeo, para praticar lógica de programação, laços de repetição e manipulação do DOM.

## Exercícios

| Pasta | Exercício | O que pratica |
| --- | --- | --- |
| `exercicios1` | Super Contador | Contagem com início, fim e passo (laço `for`) |
| `exercicios2` | Tabuada | Gerar a tabuada de um número |
| `exercicios3` | Analisador de Números | Cadastrar e analisar uma lista de números (arrays) |
| `modelobase` | Modelo base | Estrutura HTML, CSS e JS usada como ponto de partida |

## Tecnologias

- HTML
- CSS
- JavaScript

## Como usar

Abra o arquivo `modelo.html` de cada pasta no navegador.
